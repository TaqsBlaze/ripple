# Security Policy

Ripple takes security reports seriously. Please report vulnerabilities privately so the maintainers can investigate and prepare a fix before details become public.

## Supported Versions

Ripple is under active development. The current project version is `0.0.0` (unreleased development version) and is supported for security fixes.

| Version | Supported |
| ------- | --------- |
| `0.0.0` (current development version) | :white_check_mark: |
| Older or unsupported versions | :x: |

## Reporting a Vulnerability

Email vulnerability reports to [tanakah30@gmail.com](mailto:tanakah30@gmail.com). Please include the affected version or commit, affected platform, impact, and steps to reproduce. You may include a proof of concept when needed to explain the issue.

Do not report vulnerabilities through public GitHub issues, pull requests, discussions, or other public channels. Do not publish exploit details while a report is under investigation. Keep real credentials, private keys, and personal data out of reports; redact logs and reproduction material where needed.

The maintainers will review the report and reply by email. When a report is accepted, they will work on a fix and coordinate disclosure with the reporter. If it is declined, they will explain why. Fixes are usually supplied within 24 hours of a report; complex cases may take longer, and the maintainers will share an update if the estimate changes. Please coordinate any public disclosure with the maintainers.
